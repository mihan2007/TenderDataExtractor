# Bidder company details

Copy this file to `COMPANY.md` in the project root (it is git-ignored) and fill it in.
Used when preparing a bid (`docs/PARTICIPATION.md`, `docs/PREPARE_DOCS.md`) to fill forms and checklists automatically. Update it by hand when your details change.

As long as a value says `‹add›`, it is **not** filled into forms automatically — the assistant asks you for that specific field instead.

| Field | Value |
|---|---|
| Legal name (full) | ‹add› |
| Short name / trading name | ‹add› |
| Legal form (LLC, GmbH, sole trader, ...) | ‹add› |
| Company registration number | ‹add› |
| Tax ID | ‹add› |
| VAT number | ‹add› |
| SME status (micro / small / medium / no) | ‹add› |
| Registered address | ‹add› |
| Operating / postal address | ‹add› |
| Phone | ‹add› |
| E-mail | ‹add› |
| Website | ‹add› |
| Managing director / authorized signatory | ‹add› |
| Contact person for tenders — name | ‹add› |
| Contact person for tenders — position | ‹add› |
| Contact person for tenders — phone | ‹add› |
| Contact person for tenders — e-mail | ‹add› |
| Bank name | ‹add› |
| IBAN / account number | ‹add› |
| BIC / SWIFT | ‹add› |
| Default dispatch location (for logistics quotes) | ‹add› |

The full list of corporate documents and files — see `CORPORATE_DOCS.md` and the `CorporateDocs/` folder.
